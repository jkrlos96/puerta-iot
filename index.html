Guía de Conexión API / ESP32-S3

Esta interfaz expone funciones globales listas para conectarse por WebSockets, MQTT o Firebase con tu microcontrolador ESP32-S3:

1. Formato JSON enviado desde la ESP32-S3 al leer un Tag

{
  "nombre": "Carlos Mendoza",
  "uid": "A4 9B 2C 11",
  "metodo": "Tarjeta RFID",
  "autorizado": true
}

2. Funciones JavaScript disponibles en este archivo

registrarNuevoAcceso({ nombre, uid, metodo, autorizado })

Agrega la fila a la tabla con la hora exacta y, si autorizado es true, cambia el estado de la puerta a ABIERTA durante 5 segundos.

actualizarEstadoPuerta(abierta)

Sincroniza el indicador visual si un sensor magnético (Reed Switch) reporta si la puerta física está abierta (true) o cerrada (false).

Nota de Hardware: Recuerda alimentar el módulo lector RC522 estrictamente a 3.3V desde tu ESP32-S3.
